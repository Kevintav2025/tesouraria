# 💰 Sistema de Tesouraria e Controle Financeiro

Este é um sistema web focado na gestão financeira, fluxo de caixa e controle de tesouraria. O projeto reúne interfaces para lançamentos de entradas e saídas, emissão de relatórios, controle de saldos e auditoria de movimentações financeiras.

## 🚀 Demonstração

O projeto está hospedado e pode ser acessado diretamente pelo navegador através do link:
👉 [Acessar o Sistema de Tesouraria](https://kevintav2025.github.io/tesouraria/)

---

## 💻 Telas Integradas

O sistema é estruturado de forma modular para facilitar o controle financeiro através das seguintes interfaces:

* **Página Inicial (`index.html`):** Painel principal (Dashboard) com o resumo do saldo atual, receitas e despesas do mês.
* **Autenticação (`login.html`):** Tela de login para acesso restrito dos operadores de caixa e tesoureiros.
* **Fluxo de Caixa / Lançamentos:** Tela para registro detalhado de entradas (receitas) e saídas (pagamentos/despesas).
* **Relatórios Financeiros:** Interface para geração de demonstrativos, balancetes e históricos de movimentações.
* **Contas a Pagar / Receber:** Gerenciamento de contas futuras e controle de inadimplência ou pendências.
* **Configurações / Perfil:** Página de administração do sistema e dados do usuário logado.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação das tabelas financeiras, formulários de lançamento e páginas.
* **CSS3:** Interface limpa, organizada e focada em legibilidade de dados numéricos (tabelas e cards).
* **C# / JavaScript:** Lógica de programação para processamento dos cálculos, somas de saldos e backend.
